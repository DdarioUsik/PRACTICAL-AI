Программа курса

4 недели структурированного обучения с практическими заданиями

1

Обзор инструментов и метапромтинг

Освоение базовых и продвинутых техник работы с ИИ

Цели недели:

  • Получить обзор ключевых инструментов курса и научиться их быстро комбинировать
  • Освоить базовые и продвинутые техники метапромтинга
  • Создать личный Prompt-Port для хранения и версионирования шаблонов

Инструменты:

ChatGPT Gemini Claude 3 Perplexity.ai NotebookLM

Практическое задание:

Соберите свой Prompt-Port и наполните его минимум пятью метапромтами под ваши ежедневные задачи.

2

Кастомные GPT под повторяющиеся задачи

Создание персонализированных ИИ-ассистентов

Цель недели:

  • Научиться создавать кастомные GPT, «заточенные» под конкретные повторяющиеся задачи участников

Инструменты:

ChatGPT (GPT Builder + Knowledge) Tab Tab Tab Perplexity.ai

Практическое задание:

Создайте собственного GPT-ассистента, решающего вашу рутинную задачу, и продемонстрируйте его коллегам.

3

Автоматический сбор актуальных данных из интернета

Web-scraping и анализ данных с помощью ИИ

Цели недели:

  • Научиться автоматически собирать свежие данные (статьи, сайты конкурентов, RSS/новостные ленты)
  • Готовить собранные данные к анализу ИИ-ассистентом

Инструменты:

Octoparse Perplexity.ai NotebookLM

Практический проект:

Постройте сквозной pipeline: соберите данные сайта-конкурента → загрузите в NotebookLM → получите отчёт с ключевыми инсайтами с помощью LLM.

4

Быстрый выпуск продуктов

От данных к презентациям, базам знаний и сайтам

Цели недели:

  • Научиться мгновенно превращать данные, выводы и идеи в завершённые продукты
  • Создавать презентации, базы знаний, одностраничные сайты

Инструменты:

Claude 3 Gamma.app lovable.dev

Практический проект:

Используйте выводы из 3-й недели, автоматически превратите их в презентацию Claude/Gamma и опубликуйте одностраничный лендинг с lovable.dev.

Итоговое задание курса

Разработать корпоративный план постоянного внедрения ИИ-инструментов, включающий скрапинг данных, анализ и публикацию результатов в удобном формате (презентации / внутренний сайт).
